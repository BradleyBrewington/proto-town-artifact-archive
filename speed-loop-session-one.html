Time to done is measured from the moment the executor process wakes to its done marker. Of a typical 68 s, about 8 s is the agent (4 s from wake to first tool call, 4 s to sign off), 17 s is tool start-up inside episode.py (connect, home, scan), and 41 s is arm motion. Every one of the 23 runs used exactly two tool calls and no extended thinking on the nominal path; the executor never needed a prompt or model change.

Harness changes made during the session

  • Concurrency. The reviewer moved to a parallel lane after the first hour; it borrows the arm in bounded windows between runs. The judge call overlaps the next reset. This removed the 45-minute pauses.
  • Two sweep bugs. The post-run process sweep matched agents by their prompt text and killed two reviewers; then it killed reviewer tools queued for an arm window. Both fixed; the second fix required the 16:29 restart.
  • Sampler. Serpentine replaced by a weighted random draw favouring unrun, failing and outer cells, with an 8 cm spread rule. 34 distinct cells were drawn over 35 iterations.
  • Live timer and feeds on the camera page; per-cell table on the board; deadline hot-reloaded from the config.
  • Operator error. A dry-run test at 13:47 ran against the live loop and destroyed the first two real iteration bundles. Guarded against since.

Open problems, in the order they cost you

  1. Near-base ring, r < 0.15. Five reset failures with "no pitch reaches the cell". The reset tool cannot place there, so those cells are never exercised. Same gap the factory marked hard.
  2. Far edge, r ≥ 0.38. The wrist camera is blind below pitch 58, so the servo pick has no correction signal and both kills happened there. r0027 called it structural.
  3. Reset time. ~97 s per iteration, dominated by settle polling, not speed.
  4. Place bias is not learned in rehearsal. Landings sit 1 to 2 cm off in a consistent direction. Recorded episodes would learn it; the speed loop does not.
  5. Fallback never fits. The executor's second attempt starts at 60–100 s and the deadline is 90. Either the fallback goes, or the first attempt must be made to work at far cells.
